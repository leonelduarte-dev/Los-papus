# Bache Report Angostura

Aplicación frontend para registrar y consultar reportes comunitarios de baches en Angostura, Sinaloa.

## Requisitos

- Node.js 18 o posterior
- npm

## Iniciar en desarrollo

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
npm run preview
```

Los reportes se guardan en `localStorage` del navegador. La aplicación incluye datos de demostración y una representación simulada del mapa; no se conecta con el Ayuntamiento ni con un servicio externo de mapas.
